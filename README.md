# Game-sapostovlenie
Перед вами 16 квадратов: Вам необходимо выполнить игру на сопоставление. Вы нажимаете на каждый квадрат и находите одинаковые элементы. Важно! С началом каждой игры элементы меняются.
# 1. Нажимайте на любой квадратик.
# 2.Нажимаете на следующий.
# 3.Находите совпадение.
# 4.Найдите все совпадения.
# 5.Победа!
